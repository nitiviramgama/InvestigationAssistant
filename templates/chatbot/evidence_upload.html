Evidence Handling

Preserve evidence carefully and maintain source traceability.

  • Upload only evidence relevant to the selected case.
  • Preserve the original file whenever possible.
  • {% if max_upload_size %} Maximum allowed file size: {{ max_upload_size }}. {% else %} Maximum file size is subject to the server upload configuration. {% endif %}
  • Record the source or reference number whenever it is available.
  • Do not upload passwords, credentials, or unrelated sensitive information.
  • Uploaded files become part of the investigation record.

Investigation Workflow

  1. Identify the evidence source.
  2. Upload the original file.
  3. Preserve source references.
  4. Extract relevant information.
  5. Link evidence with people, events, and other entities.
